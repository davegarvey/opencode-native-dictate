# Model licenses and attribution

Native Dictate downloads model snapshots to the user's Application Support directory during explicit setup. The repository and plugin package do not redistribute model weights. Keep each model's original model card and license terms with its downloaded assets when copying or redistributing them.

| Selected model | Upstream license label | Attribution/source |
|---|---|---|
| `mlx-community/parakeet-tdt-0.6b-v3` | CC-BY-4.0 | MLX Community's conversion of NVIDIA Parakeet TDT 0.6B v3. See the [MLX model card](https://huggingface.co/mlx-community/parakeet-tdt-0.6b-v3) and [NVIDIA source model](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3). |
| `mlx-community/Qwen3-ASR-0.6B-8bit` | Apache-2.0 | MLX Community's 8-bit conversion of Qwen3-ASR 0.6B. See the [MLX model card](https://huggingface.co/mlx-community/Qwen3-ASR-0.6B-8bit) and [Qwen source model](https://huggingface.co/Qwen/Qwen3-ASR-0.6B). |

Model cards publish these license labels and conversion relationships. Verify the files and terms at the exact pinned revisions before distributing model assets. MLX Audio itself is a separate dependency and retains its own upstream license and notices.
